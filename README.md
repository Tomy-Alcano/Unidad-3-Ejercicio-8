# Unidad-3-Ejercicio-8
Programacion 3 Unidad 3 Ejercicio 8
Ejercicio 8 — Modificación de clientes con UPDATE
Este ejercicio incorpora la operación de modificación: el usuario selecciona un cliente de la tabla, sus datos se cargan en el formulario, los edita y confirma los cambios.

Tomá como base el ejercicio anterior y agregá la siguiente funcionalidad:

Al hacer clic sobre una fila de la tabla, los datos del cliente seleccionado deben cargarse en los campos del formulario. El campo ID debe mostrarse en una etiqueta (no editable) para identificar el registro
Un botón con el texto "Modificar cliente", que inicie deshabilitado
Cuando haya una fila seleccionada y los campos estén cargados, el botón "Modificar cliente" debe habilitarse
Al presionar "Modificar cliente", debe ejecutarse un UPDATE en la base de datos para el cliente cuyo ID coincida con el seleccionado
Tras la modificación, la tabla debe recargarse y los campos deben limpiarse
💡 Tip: guardá el ID del cliente seleccionado en una variable de instancia para poder usarlo en la consulta UPDATE. Recordá que el ID no debe ser editable por el usuario.
